プライバシーポリシー

制定日: 2026年9月29日　最終更新日: 2026年10月6日

「推しさいふ」（以下「本アプリ」といいます）における利用者情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 取得する情報

本アプリは、利用者を特定できる個人情報（氏名、メールアドレス、電話番号、位置情報、端末識別子など）を取得しません。

本アプリの利用に伴い、次の情報をお使いの端末内にのみ保存します。

  • 登録した推しの情報（名前、カラー、アイコン、推し始めた日）
  • 支出の記録、イベント、推し貯金、月の予算などの設定
  • App 内課金の購入状態

これらの情報は開発者のサーバー等に送信されず、開発者を含む第三者が閲覧することはありません。ウィジェットに表示するための情報も、同じ端末内のウィジェットとの間でのみ共有します。

2. 外部への通信

本アプリが外部と通信するのは、App 内課金の購入・購入の復元のために Apple の StoreKit と通信する場合に限られます。

3. App 内課金

App 内課金（サブスクリプション・買い切り）は Apple の StoreKit を通じて処理されます。決済情報の取り扱いは Apple のプライバシーポリシーに従い、開発者がクレジットカード番号等の決済情報を取得することはありません。

4. 通知

イベントのお知らせは、端末内で予約されるローカル通知です。通知のために情報を外部へ送信することはありません。通知は iPhone の「設定」アプリからいつでも停止できます。

5. Face ID

Face ID はアプリのロックを解除するためにのみ使用します。認証は iOS が端末内で行い、本アプリや開発者が顔の情報を取得することはありません。

6. シェアカード

シェアカードの画像は端末内で作成されます。利用者が共有操作を行った場合に限り、利用者が選んだアプリやサービスに画像が渡されます。

7. 広告・解析・トラッキング

本アプリは広告を表示しません。また、アクセス解析ツールや広告用の SDK を組み込んでおらず、利用者の行動の追跡（トラッキング）を行いません。

8. 第三者への提供

本アプリは前記のとおり個人情報を取得しないため、利用者の情報を第三者に提供・販売することはありません。

9. 情報の削除

本アプリで登録した推し・支出・イベント・推し貯金は、各画面から削除できます。また、本アプリを端末から削除すると、端末内に保存された情報はすべて削除されます。

10. 本ポリシーの変更

本ポリシーは、法令の変更や本アプリの機能の変更等に応じて改定することがあります。重要な変更がある場合は、本ページでお知らせします。改定後の本ポリシーは、本ページに掲載した時点から効力を生じます。
