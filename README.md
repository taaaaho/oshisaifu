# oshisaifu

iOSアプリ「推しさいふ」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/oshisaifu/
- プライバシーポリシー: https://taaaaho.github.io/oshisaifu/privacy.html
- 利用規約: https://taaaaho.github.io/oshisaifu/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

ソースコードは非公開リポジトリ（`oshisaifu-code`）で管理しています。
